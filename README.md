# OpenHands PR Testing

## Square Function

The scientific calculator supports a `square(value)` function.

### Expected behavior

- `square(5)` returns `25`.
- `square(-4)` returns `16`.
- `square(0)` returns `0`.
- `square(2.5)` returns `6.25`.
- The function accepts integer and floating-point inputs.
- The function returns the input multiplied by itself.
